O ÚLTIMO GRITO — V0.9.2 · EDIÇÃO SONORA
=========================================

ATUALIZAÇÃO:
- Todas as funcionalidades da V0.9.1, incluindo as oito artes .webp.
- Oito trilhas instrumentais originais, produzidas para esta versão:
  menu, amizade, romance, investigação, tensão, perseguição, luto e lago.
- Oito efeitos: toque de opção, mensagem, impacto, batidas na porta,
  passos, água, batimento cardíaco e chuva.
- Músicas mudam automaticamente segundo a cena e a narrativa. As
  sequências de perseguição existentes têm tratamento próprio.
- Transições de volume suaves entre músicas; o controle de volume usa
  Web Audio para compatibilidade com iOS/Safari e computadores.
- Menu CONFIGURAR ÁUDIO: volumes independentes para música/efeitos,
  desligar/ligar e testar os sons.
- Áudio inicia DESLIGADO em cada visita até um toque do usuário.
- Volumes são lembrados neste navegador, mas NÃO alteram os slots.
- Os 3 slots, formato de save e roteiro dos capítulos 1–5 estão intactos.

EXECUÇÃO:
- Computador: extraia o ZIP e abra index.html no Chrome, Edge ou Safari.
- iPhone: use o link publicado do Render no Safari; no app Arquivos
  a visualização de index.html não executa um jogo completo.
- Mantenha todos os arquivos juntos na RAIZ, incluindo sound.js e
  os dezesseis arquivos som_*.mp3 (nenhuma pasta aninhada necessária).
- Após abrir, toque em ♪ LIGAR ou acesse CONFIGURAR ÁUDIO e ATIVAR ÁUDIO.
- Alguns navegadores interrompem o áudio quando vão para segundo plano.

ATUALIZAÇÃO NO GITHUB + RENDER:
1. Extraia o ZIP.
2. No GitHub do projeto, clique Add file > Upload files.
3. Para atualizar desde a V0.9.1, envie index.html, game.js,
   style.css, sound.js e TODOS os dezesseis arquivos som_*.mp3.
   Também pode enviar todos os arquivos da pasta, se preferir.
4. Os MP3 devem ficar ao lado do index.html; NÃO enviar o ZIP fechado.
5. Clique Commit changes. Se o Render tiver deploy automático ativo,
   aguarde o deploy ficar Live e atualize a página do jogo no Safari.
6. Se as trilhas não tocarem, confira se TODOS os MP3 foram publicados,
   aumente os volumes e toque em LIGAR SOM.

SALVAMENTOS:
- Chaves de storage preservadas: ultimo-grito-slot-1, -2 e -3.
- Não houve alterações de nós, flags ou estrutura do JSON.
- As preferências sonoras usam chave própria e não entram no save.
- Exporte cada slot antes de atualizar, por precaução.
- Salvamentos locais não sincronizam automaticamente entre aparelhos.

TRILHAS E SONS:
- Música/efeitos são composições e sínteses produzidas exclusivamente
  para esta atualização. Não incluem gravações protegidas de filmes
  ou músicas comerciais nem necessitam de APIs externas.
- A mixagem usa arquivos MP3 compatíveis com navegadores comuns.
